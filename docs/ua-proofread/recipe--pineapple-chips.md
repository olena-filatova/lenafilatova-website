    to "тож найкраще в міру", which also now matches the parallel phrasing used
    in the sibling `spiced-apple-chips` entry ("Найкраще помірно...").
  - `title`: "Чипси з ананаса" (noun + genitive) didn't match the adjective-based
    naming used by every other chip recipe in the file ("Бурякові та ананасові
    чипси", "Бананові чипси", "Пряні яблучні чипси"). Changed to "Ананасові
    чипси" for terminology consistency across the site.
